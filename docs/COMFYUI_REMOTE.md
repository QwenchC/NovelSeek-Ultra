# ComfyUI 外网地址配置与连接诊断

手机不在电脑局域网时，应使用穿透服务的对外地址，不能使用电脑的局域网 IP、本地端口或手机上的 localhost。Android 1.6.1 支持公网地址和连接诊断；1.6.2 进一步支持在“设置 → 图像生成引擎 → ComfyUI”核对并授权单个服务器的自签名证书。APP 不会创建隧道或修改 ComfyUI 的服务器安全配置。

## 地址填写

| 连接方式 | APP 地址示例 | 端口含义 |
| --- | --- | --- |
| 同一局域网 | `http://192.168.1.100:8188` | 电脑实际监听端口 |
| TCP 穿透 HTTP | `http://node.example.com:35961` | 穿透服务分配的远程端口，不是电脑本地端口 |
| TCP 穿透 HTTPS | `https://node.example.com:35961` | 自动 HTTPS 或 HTTPS 服务的远程端口，证书必须匹配主机；自签名证书需在本机明确核对授权 |
| HTTP／HTTPS 域名隧道 | `https://comfy.example.com` | 使用绑定域名及服务约定端口，不能用节点 IP 代替绑定域名 |
| 反向代理子路径 | `https://example.com/comfy` | APP 会保留 `/comfy`，追加各个 API 路由 |

以上均为示例，不是可用服务。裸 `主机:端口` 会按 HTTP 补全，不添加 `8188`；建议始终写明协议。樱花 FRP 对 TCP 与 HTTP(S) 的域名、端口要求不同，配置应与隧道类型一致。[樱花 FRP 官方 Web 穿透指南](https://doc.natfrp.com/app/http.html)

只填写 ComfyUI 服务基址，不追加 `/system_stats`、`/prompt` 或 `/view`，不填写查询参数、网页登录地址、用户名或密码。主机和端口的选择会决定真实请求的 Host，不需要手动改写 Host 头。

输入后可先点击“测试 ComfyUI 连接”，测试使用当前草稿；确认正确后点击“应用地址”。未应用时，生成仍使用之前保存的地址。一次连接成功仅说明 API 可以访问，不证明固定的 z-image-turbo 工作流、模型文件和节点已配置完成。

## 没有自有域名时使用自签名 HTTPS

不需要购买域名，也不需要在 Android 系统安装根证书。前提是隧道提供的域名与服务器证书中的域名一致；APP 保留域名、有效期和完整证书指纹校验。[Android 官方 TLS 指南](https://developer.android.com/privacy-and-security/security-ssl)、[樱花 FRP 证书说明](https://doc.natfrp.com/frpc/ssl.html)

1. 在电脑上确认穿透客户端实际使用的公共证书，独立取得其完整 SHA-256 指纹。不要发送私钥、隧道令牌或密码。
2. 在 APP 选择 ComfyUI，将地址写为完整 `https://隧道域名:远程端口`，点击“应用地址”。不要换成 IP，也不要省略 HTTPS。已有 HTTP 地址可以点击“切换 HTTPS 并核对隧道证书”，再应用。
3. 点击“查看并核对服务器证书”。逐字核对弹窗中的完整 SHA-256 与电脑端证书；弹窗本身只是网络观察结果，不能独立证明服务器身份。
4. 指纹一致且有效期正常时，勾选“我已核对完整指纹，确认这是我的服务器”，再点击“仅信任此主机和端口”。默认未勾选，不能直接批准。
5. 点击“测试 ComfyUI 连接”，通过后再生成图片。生成的提交、进度查询和图片下载共用同一个证书授权。

证书授权仅保存在这台设备，不进入小说 ZIP／JSON 备份，也不参与 Android 系统备份或设备迁移。新手机需要单独核对授权。相同 HTTPS 主机和端口下的代理路径共享授权；其他域名、端口、HTTP 地址不继承它。可以随时点击“撤销此服务器的信任”，停止旧连接使用该授权。

证书更换、重新生成或到期时连接会失败。先在电脑确认新证书，再回到 APP 核对完整新指纹；不要因为连接失败就盲目批准。证书数据异常或授权读取失败也会拒绝使用授权。撤销保存失败时，APP 会阻止当前进程继续使用授权并提醒重试；在成功保存撤销前，不保证重启后仍处于撤销状态。

## 故障提示

- **HTTP 501 且提示自动 HTTPS**：隧道拒绝明文 HTTP，网页可能用 JavaScript 跳转。将地址改为同域名、端口和路径的 `https://` 后重新测试；APP 不执行网页脚本。
- **HTTPS／TLS 失败**：检查证书是否受信任、是否有效、是否匹配地址中的主机。使用 IP 通常不能代替域名证书。樱花自动生成的自签名证书不会被客户端自动信任；1.6.2 可按上文核对授权。
- **服务器证书已改变**：旧授权不能匹配当前证书。先从电脑端取得新证书的完整指纹，核对后重新授权。
- **证书已过期或尚未生效**：检查手机时间与隧道证书有效期，修复服务端证书；重新授权不会取消有效期校验。
- **HTTP 3xx**：APP 不跟随 ComfyUI 重定向，以免将请求或授权转交其他地址。填写服务器最终基址，确保 API 路由直接响应；不要填写登录页地址。
- **HTTP 200 但不是 ComfyUI API**：可能连到了认证页、节点介绍页或错误的代理路径。APP 校验的是 `/system_stats` 数据，不是网页能否打开。[ComfyUI 官方路由实现](https://github.com/Comfy-Org/ComfyUI/blob/master/server.py)
- **HTTP 401／403**：网关需要授权或拒绝访问。当前客户端不支持交互式网页登录和网关凭据，不要通过移除访问保护来解决。
- **HTTP 404**：检查基址和代理子路径，确保 `/system_stats`、`/prompt`、`/history/{id}`、`/view` 都会转发到 ComfyUI。
- **HTTP 502／503／504**：检查 ComfyUI 是否启动、隧道是否在线、本地目标地址与监听端口是否一致。
- **DNS、连接失败或超时**：检查手机网络、远程域名和端口，以及穿透节点的使用限制。

## HTTPS 与安全边界

优先使用受信任 HTTPS 或受保护的私人连接，不要公开无鉴权 ComfyUI，也不要在公网 HTTP 传输敏感提示词或图片。证书授权只验证服务器身份和保护传输，不能阻止其他人使用公开的无鉴权服务。

APP 不关闭 TLS 或主机名校验、不自动信任网络返回的证书、不放宽服务端的 Host／Origin 检查。授权只影响 ComfyUI 的独立连接，不改变文本模型 API、Pollinations 或系统全局证书设置。检查证书时只观察 TLS 证书并拒绝完成握手，不发送 HTTP 请求、提示词或凭据。

1.6.2 已在 Android 模拟器通过真实公网 HTTPS 入口完成一次 256×256 图片的提交、轮询、下载与解码；实际手机移动网络仍需单独验收。详见 [1.6.2 验证记录](1.6.2-VERIFICATION.md)。
