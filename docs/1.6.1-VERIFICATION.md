## 网络诊断和人工验收

只读检查用户提供的外网入口时，HTTP 返回樱花 FRP 自动 HTTPS 提示页；HTTPS 默认信任校验失败，证书检查显示樱花自动生成的自签名证书。没有修改穿透服务、证书或 ComfyUI 设置，也没有向公网服务提交生成任务。该入口的证书信任问题仍未解决。

当前没有连接 Android 设备，也没有可用的本地 AVD。以下项目仍需人工验收：

1. 从 1.6.0 备份后覆盖升级，检查原小说、模型设置和历史会话。
2. 在智能体、编辑器和工作台中打开候选，检查三个标签页、长正文末段、窄屏、手势／三键导航与键盘弹出时的悬浮按钮；核对忙碌禁用、部分采用及拒绝。
3. 经典与双智能体分别锁定项目，打开自动继续和忽略手动审稿，使用真实 API 连续生成至少两章；检查正文落盘、下一章来源、手动停止与息屏恢复。
4. 保留待审稿后开启新选项，确认仍需手动审核；修改正文或设定后尝试自动采用，确认暂停且不覆盖新内容；导入带授权的备份，确认授权关闭。
5. 在大书库上测量设置页首次打开、输入地址／密钥、模型保存和项目统计；展开高级设置并切换配置，确认未应用草稿保留。
6. 在手机移动网络下连接证书可信的 ComfyUI 外网入口，分别检查连接、图片生成、代理路径和取消；不能用本机模拟 HTTP 测试宣称实测通过。
