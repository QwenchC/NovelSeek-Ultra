# NovelSeek Ultra 1.6.1 更新说明

1.6.1 改进审稿操作、连续章节生成和设置页响应，并补齐 ComfyUI 公网连接的地址处理与诊断。Android 显示版本为 `1.6.1`，内部版本号为 `16`；保留经典与双智能体、旧项目结构以及与桌面 2.1.0 的 ZIP／JSON 备份兼容。本次不修改桌面端版本。

## 悬浮审稿按钮

“通过并采用”始终位于审核工作台右下角，不依赖“提出修改意见”展开或键盘出现。编辑器、项目工作台和智能体会话共用此组件，候选正文、差异对照、审稿意见三个页面均可直接采用。

逐段选择后按钮显示“采用所选修改”；原拒绝和作者意见修订入口保留。忙碌、正文为空、来源不允许采用或预览尚未完成时，按钮不可提交。底部列表留白及键盘、导航栏边距用于避免遮挡末段正文。

## 连续章节生成

在智能体页面菜单打开“会话设置 / 自动执行”，先选择锁定项目，再按需开启两个独立选项：

- “自动继续”跳过一般敏感工具执行前的逐次确认。
- “忽略手动审稿”在每次动作新生成候选后，使用正常的来源复核与采用事务自动写入正式正文。

连续写章需要同时开启这两个选项，并给出明确的章节范围或任务目标。它适用于经典和双智能体；双智能体仍需依据已提交的正文证据完成计划步骤，不把候选生成当作任务完成。步数、生成额度、停止操作及高风险确认边界仍然有效，不是无限运行模式。

新选项默认关闭，按会话保存。旧版本的“自动继续”不推导新权限；导入会话总是关闭自动审稿。切换项目撤销原授权，设置保存同时核对会话、项目和任务状态。已经等待手动审核的稿件不会因为开启开关而被追认。

自动采用只处理本次会话、本次动作、锁定项目下的完整候选。正文、规划或生成上下文变化时保留草稿并暂停，不覆盖新内容。正式采用后，下一章会等待本章启用的摘要、实体、知识库和容器更新；停止或超时会取消并等待这些子任务结束，避免延迟更新影响下一章。后处理超时不回滚已经采用的正文。

## 设置页响应

- 知识库、项目知识库统计和增强层设置首次进入时按需展开；展开后保持草稿和任务状态。
- 模型密钥与 Embedding 配置在后台读取，只对相关配置或安全存储变更刷新；无关小说状态变化不再重复解密。
- 项目统计、章节正文扫描和来源哈希在后台执行，提供加载、失败与重试状态。
- 模型保存、切换、删除，以及主题、语言、智能体默认选项等设置在后台提交，提交期间阻止重复操作。
- Pollinations 密钥和 ComfyUI 地址先编辑本地草稿，点击“应用密钥”或“应用地址”才保存，避免逐字写入存储。未应用的草稿在相关配置后台刷新时保留。

这些改动移除了已定位的主线程文件扫描、解密与逐字符持久化路径；低端手机上的实际帧率与打开耗时仍需设备测量。

## ComfyUI 外网连接

支持完整 HTTP／HTTPS 地址、公网 `主机:远程端口`、IPv6 以及反向代理子路径，不擅自把公网端口替换为本地 `8188`。省略协议的地址按 HTTP 处理；启用自动 HTTPS 的隧道应明确填写 `https://`。

连接测试使用当前输入，生成使用已经“应用”的地址。测试验证 `/system_stats` 的实际 ComfyUI API 数据，不把返回 HTTP 200 的登录页或普通 JSON 当作连接成功。可区分 DNS、TLS、401／403、404、网关错误和超时；樱花 FRP 的自动 HTTPS 提示页会明确建议修改协议。提交、任务轮询和图片下载使用同一地址规则，取消下载不再触发重试。

客户端不绕过证书、Host 或 Origin 检查，也不支持地址内用户名、密码、令牌或交互式网关登录。自动 HTTPS 的自签名证书仍需在服务端解决信任问题；地址支持与诊断改进不代表公网隧道已经可用。详见 [外网连接指南](COMFYUI_REMOTE.md)。

## 安装和验证

476 项 JVM 回归全部通过，Lint 0 错误、43 条警告；Debug 与 AndroidTest APK 构建成功。ComfyUI 网络测试使用本机模拟 HTTP 服务，包含提交、历史轮询、图片下载和取消；生成与自动审稿测试不调用真实模型 API。校验值及人工验收步骤见 [验证记录](1.6.1-VERIFICATION.md)。

Release APK 为 Android Debug 构建，证书与 1.6.0 发布包一致。安装前请导出作品备份；覆盖升级、悬浮按钮的窄屏和键盘位置、真实模型连续写章、息屏及公网手机连接尚待实机验收。若签名冲突，不要通过卸载旧版强行安装，以免丢失作品。
