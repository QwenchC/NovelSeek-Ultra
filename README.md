# NovelSeek Ultra

> 一款基于 AI 的 Android 小说创作助手，由桌面端项目 [NovelSeek-Ultra-PC](https://github.com/QwenchC/NovelSeek-Ultra-PC) 迁移而来，现在两者已实现机制同步，备份格式与桌面端 NovelSeek-Ultra-PC 完全互通，可无损互导。

---

## 功能概览

### 📖 长篇小说
- 创建与管理多个长篇小说项目
- **副本（分卷）机制**：大纲生成副本，项目页副本列表可展开/收起；点开某个副本显示其下剧情弧线
  - 副本、弧线均支持 **AI 生成（可指定一次生成几个 + 自定义要求指令）** 与手动添加
  - 副本可重命名 / 调整序号 / 编辑描述；弧线可编辑、按序号快捷调序、规划章节
  - 旧版项目（仅有弧线、无副本）自动迁移并归入"副本1"
- 大纲保存支持选择性覆盖世界观、时间线、角色、副本等字段
- 逐章 AI 写作：世界观/时间线/角色资料作为稳定硬前缀，版本化“小说状态编译器”统一动态前情、角色状态、伏笔、容器与长程记忆
- 章节生成页可在当前章节**前 / 后插入新章节**，后续章节序号自动顺延
- 章节封面头图批量生成（跳过已有图片）
- 宣传图 & 封面图 AI 生成

### 📄 短篇小说
- 创建与管理多个短篇小说项目
- AI 生成严格格式大纲（世界观 / 时间线 / 章节列表，无弧线）
- 从大纲一键导入空白章节
- 逐章 AI 写作，章节间通过统一小说状态自动衔接

### 🧙 角色管理
- 每个项目独立的角色库
- 从 AI 生成大纲中批量导入角色
- **新建角色支持一句话 AI 快速生成**：输入一句描述即可自动填写姓名/性别/身份/性格/背景/动机/形象等全部字段；生成时注入大纲、世界观与境界体系，确保角色与小说契合，并自动匹配境界
- 角色信息（背景、外貌、性格等）自动注入章节生成

### 🌍 世界观 & 修炼体系
- 独立世界观信息管理
- 修炼体系（境界）编辑对话框
- 世界观信息注入大纲与章节生成

### 📤 导出
- 章节文本导出为 **PDF** 或纯文本

### 🕘 版本管理（全项目快照）
- 项目页「版本」入口，把**整个项目**（章节正文、大纲、世界观、角色、插图、宣传图等）打包成版本快照，类似 `git commit`
- 支持手动保存版本、AI 覆盖章节前自动备份；可查看历史、一键回退到任意版本（回退前自动备份，可再次撤销）
- 回退后自动清理失效的知识库向量，并标记需重建的章节，支持**仅重建变化章节**的增量重建

### 🤖 小说问答（AI 智能体）
- 项目页 / 章节生成页「问答」入口，用自然语言询问关于**当前版本**小说的任何问题（如"角色现在什么境界""A 和 B 是什么关系""目前发生了哪些事"）
- 混合检索：结构化数据（角色 / 境界 / 关系 / 事件 / 知识条目 / 摘要 / 章节列表）始终可用，配置本地知识库后额外检索正文片段
- AI 只依据检索到的资料作答、可标注章节号，对话按项目持久化保存，支持追问与流式输出

### ✨ 智能体（Agent）
- 底栏正中的醒目入口，一个**会使用工具的自主智能体**：用设置里的文本/图片/知识库引擎 + DuckDuckGo 联网搜索，像人一样操作整个软件
- 一句话可完整生成小说项目：建项目 → 境界/世界观 → 大纲 → 角色与立绘 → 封面 → 副本/弧线/章节规划 → 逐章生成；也能精准操作（改/删/移 副本·弧线·章节、润色、插章、改名、推文、矛盾审阅、版本管理等，60+ 工具）
- **链式执行流**自上而下可见；可随时**停止 / 继续 / 运行中插话**；智能体也会在需要时**反问**你
- **半自主**：不可逆/耗费操作默认逐步确认；可「始终允许」或锁定项目后开启**自动继续**
- **多会话**：可命名智能体、新建/切换/删除会话，各自独立保存
- **上下文管理**：输入区圆环分段显示固定提示、会话历史、输出预留与剩余空间；接近上限时本地自动压缩，也可手动压缩
- **后台执行与恢复**：前台服务 + 通知，**息屏/切后台仍继续**；真实进度心跳、持久化检查点与有限自动重试会识别“界面运行但任务已失活”
- 隐私：绝不输出 API 密钥等私密信息

### 🎧 听书
- 底栏独立「听书」入口，可收听任意短篇 / 长篇小说项目
- 语音引擎用 **微软 Edge 免费神经语音**（无需密钥），多种中文音色 + 语速可选
- **分段流式朗读**：章节按句切段，逐段合成并播放，并预取下一段使衔接连贯（切换音色/语速会即时重备下一段）
- 切换章节、章末自动续下一章、N 段进度滑块可拖动跳段；离开页面自动保存进度，重进恢复

### 📦 容器（AI 自演化知识库）
- 项目页 / 章节生成页「容器」入口，新建可按角色 / 按章节分块、或不分块的资料容器
- 勾选**按章更新**：每次保存最新章时，AI 在各分块当前值基础上演进出新条目（无变化则跳过），并记录触发的章节，形成属性进化链
- 勾选**影响章节生成 / 影响副本生成 / 影响剧情弧线生成**：容器最新值作为**软引导**注入对应的 AI 生成，避免前后矛盾，同时允许自然演进
- 容器信息（名称 / 各开关）可随时修改，类型创建后锁定
- 分块随角色 / 章节数量自动增减；值链新旧可见、最新值可手动修改；受版本管理影响，每个分支独立

### 🎨 图片生成引擎
- **Pollinations**（默认）：云端免费图片生成，无需本地环境
- **ComfyUI**：连接局域网内本地运行的 ComfyUI，使用 `z-image-turbo` 工作流，支持高质量本地推理
  - 设置中填写局域网 IP 地址（如 `http://192.168.1.100:8188`）
  - 内置连接测试按钮

### ⚙️ 设置
- 配置 AI 服务的 API Key 与 Base URL；各 API 配置区附带获取地址超链接
- 选择图片生成引擎：Pollinations（云端）或 ComfyUI（本地）
- 密钥本地加密存储（Android Keystore + `security-crypto`）
- **数据备份/恢复**：完整导出/导入全部内容——项目、章节正文与草稿、章节插图、大纲/世界观/时间线、角色、副本与弧线、容器、摘要/实体、小说问答记录等（向量索引可重建，故不入备份）

## 快速开始

### 环境要求

- Android Studio Meerkat 或更新版本
- JDK 11（Android Studio 内置 JBR 即可）
- Android SDK 36

### 构建运行

```bash
git clone https://github.com/QwenchC/NovelSeek-Ultra.git
cd NovelSeek-Ultra
./gradlew assembleDebug
```

或在 Android Studio 中直接 **Run ▶**。

### 自动化验证

```powershell
# JVM 单测、Android Lint 与 Debug APK
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug

# 编译设备侧测试 APK
.\gradlew.bat :app:assembleDebugAndroidTest

# 在已连接的 Android 模拟器上执行备份导入的五阶段进程死亡恢复矩阵
.\scripts\test-backup-import-process-death.ps1
```

进程死亡脚本默认拒绝真机，只会安装 Debug/Test APK，不会清除应用数据。需要指定模拟器时使用
`-Serial emulator-5554`；确需在真机运行时必须显式添加 `-AllowPhysicalDevice`。

### 配置 API Key 与图片引擎

打开应用 → 右上角 **设置（⚙）** → 填写：

| 字段 | 说明 |
|------|------|
| API Base URL | AI 文本服务地址，例如 `  https://api.deepseek.com` |
| API Key | 对应模型平台服务的密钥 |
| 图片引擎 | `Pollinations`（云端）或 `ComfyUI`（本地） |
| ComfyUI 地址 | 仅 ComfyUI 模式需填，填局域网 IP，如 `http://192.168.1.100:8188` |

> **ComfyUI 须知**：手机与运行 ComfyUI 的电脑需在同一局域网。应用使用内置 `t2i-lumicreate.json` 工作流（z-image-turbo，不带 LoRA）。

### 2. 初次配置：设置 AI 服务

首次使用需在**设置**页配置 AI 服务，否则所有 AI 功能不可用。

#### 2.1 进入设置

点击底部导航栏右侧 **⚙️ 设置**。

![设置页总览](docs/screenshots/02_settings_overview.png)

#### 2.2 配置文本模型（API）

在**文本模型配置**区块，点击 **「+ 添加」** 新建 API 配置：

- **API Base URL**：AI 文本服务地址（例如 `https://api.deepseek.com`）
- **API Key**：服务密钥（DeepSeek密钥获取地址`https://platform.deepseek.com/api_keys`）
- **模型名称**：填写你使用的模型 ID

填写后点击**测试连接**，出现绿色成功提示则配置正确。

对 DeepSeek / OpenAI 直连配置，应用会请求服务商返回 Token 与前缀缓存 usage；设置页只在服务商返回完整命中/未命中数据时计算本次运行命中率。未返回 usage 的兼容接口会显示为“不可观测”，不会把未知数据当作 0% 或 100% 命中。

![添加文本模型配置](docs/screenshots/02_settings_api_config.png)

#### 2.3 （可选）配置 Embedding 服务（API）

在**本地知识库（实验性）**区块，点击 **「启用本地知识库」** 启动本地知识库：

- **API Base URL**：Embedding 服务地址（例如阿里云百炼 `https://bailian.console.aliyun.com/cn-beijing?tab=model#/api-key`）
- **API Key**：服务密钥（例如阿里云百炼 `https://dashscope.aliyuncs.com/compatible-mode/v1`）
- **模型名称**：填写你使用的模型 ID（例如阿里云百炼的text-embedding-v3）
- **维度**：默认1024

填写后点击**测试连接**，出现蓝色成功提示则配置正确。

#### 2.4 配置图片生成引擎

在**图片生成引擎**区块选择：

- **Pollinations**：云端免费，[但最好创建密钥](https://enter.pollinations.ai/#keys)，否则默认采用旧版文生图，质量较低
- **ComfyUI**：连接本地局域网 ComfyUI（适合有本地 GPU 的用户，且部署了"./workflows/t2i-lumicreate.json"的工作流并运行通过）
  - 填写局域网 IP，如 `http://192.168.1.100:8188`
  - 点击**测试 ComfyUI 连接**确认可达

> ⚠️ 使用 ComfyUI 时，手机与运行 ComfyUI 的电脑必须在同一 Wi-Fi 网络下。

### 3. （**仅用于20章以下项目，建议直接跳过此段看长篇小说项目介绍**）短篇小说：完整创作流程

短篇小说适合创作结构完整、篇幅较短的故事（5–20 章）。

#### 3.1 新建项目

在**短篇小说**页，点击右下角 **「＋ 新建项目」**：

- 填写**项目名称**（必填）、类型、简介
- 点击**创建**，自动进入项目页

![新建短篇项目](docs/screenshots/03_short_create.png)

#### 3.2 生成大纲

在项目页点击 **「大纲」** 按钮，进入大纲页面。

**AI 生成流程：**

1. 填写**世界观描述**（世界背景、核心设定）
2. 填写**时间线**（故事发生的时间背景）
3. 填写**额外要求**（风格、禁忌内容等，可留空）
4. 选择**章节数量**（拖动滑块）
5. 点击 **「生成大纲」**，等待 AI 流式输出

![短篇大纲生成](docs/screenshots/03_short_outline_generate.png)

**大纲格式说明（AI 输出）：**
```
## 世界观
...

## 时间线
...

## 章节大纲
### 章节标题A
情节：...
关键场景：...

### 章节标题B
...
```

#### 3.3 保存大纲

AI 输出完成后，点击 **「保存大纲」**，弹出保存选项：

- 勾选需要覆盖的字段：**世界观**、**时间线**、**章节列表**（已有内容时会提示冲突）
- 点击**确认保存**

![保存大纲对话框](docs/screenshots/03_short_outline_save.png)

#### 3.4 从大纲导入章节

回到项目页，在**章节列表**标题右侧点击 **「从大纲导入」**：

- 弹窗展示从大纲中解析出的章节列表
- 确认后一键创建全部空白章节，顺序与大纲一致

![从大纲导入章节](docs/screenshots/03_short_import_chapters.png)

#### 3.5 逐章生成内容

点击章节卡片，进入**章节编辑器**。在编辑器中：

1. 上方**规划区**显示该章的目标、冲突（来自大纲）
2. 点击 **「✨ 生成」** 按钮，AI 自动注入上下文（前章摘要、角色信息、世界观）并生成
3. 流式文字先作为实时预览显示，不会直接覆盖正式正文
4. 生成完成后进入**候选稿审核**；选择“采用”才写入正文，选择“拒绝”则保留原文

重复此步骤，逐章完成全文。

### 4. 长篇小说：完整创作流程

长篇小说支持**副本（分卷）+ 剧情弧线**的层级结构，适合 20 章以上的连载作品。

#### 4.1 新建项目

在**长篇小说**页，点击 **「＋ 新建长篇」**，流程与短篇相同。

#### 4.2 生成大纲

进入项目 → **「大纲」**，建议在**AI 生成大纲**栏可输入额外要求，也可不输入，世界观和时间线也可不输入，直接点击**生成**按钮，长篇大纲文本生成并额外输出**副本（分卷）结构**。

保存时可选择覆盖：世界观、时间线、角色、**副本与弧线**。

#### 4.3 管理副本与剧情弧线

项目页中间区域显示**副本列表**（可展开/收起）：

- **每个副本**下方列出其所属的剧情弧线
- 点击副本名称旁的 **✏️** 可重命名或编辑描述
- 点击 **「＋ 添加弧线」** 手动新增剧情弧线
- 点击副本旁 **「AI 生成」** 可批量 AI 生成弧线（可指定数量和要求）

![长篇副本与弧线结构](docs/screenshots/04_long_volumes_arcs.png)

#### 4.4 快捷调整副本和弧线顺序

每个副本和每条弧线卡片下端有 **↑↓ 按序号调序** 快捷按钮，点击即可调整在副本内的先后顺序，后续章节序号自动顺延。

#### 4.5 章节生成（插入机制）

长篇章节生成与短篇相同，但额外支持：

- 在当前章节**前**或**后**插入新章节（**章节生成页面**的编辑器上方的**规划**框内的按钮**插入章节**操作）
- 插入后所有后续章节序号自动+1

### 5. 角色管理

每个项目有独立的角色库，点击项目页的 **「角色」** 按钮进入。也**可在大纲生成前在此处输入角色信息**，大纲文本中的角色信息会依据这里的角色信息生成。

#### 5.1 从大纲导入角色

点击顶栏右侧 **👤＋（从大纲导入）** 图标：

- 应用自动解析当前大纲中的角色信息
- 勾选需要导入的角色（已存在的默认跳过）
- 点击**导入**，角色信息批量写入角色库

![从大纲导入角色](docs/screenshots/05_char_import.png)

#### 5.2 手动新建 / AI 快速生成角色

章节编辑器是写作的核心页面，有两个 Tab：

| Tab | 功能 |
|-----|------|
| 最终稿 | 定稿版本，用于导出 |

![章节编辑器总览](docs/screenshots/07_editor_overview.png)

#### 7.1 AI 生成章节

点击 **「✨ 生成本章」**，AI 自动注入：

- 大纲目标与冲突（来自章节规划）
- 前 3 章摘要（越近越详细）
- 所有角色信息（主角尤其详细）
- 世界观与时间线
- 当前境界信息（如有）
- 容器最新值（如启用了"影响章节生成"的容器）
- 设置页的本地知识库的索引片段 + 章节摘要 + 全书梗概（如有）

这些来源不会各自随意拼接。应用会先把现有的弧线进度、全书/弧线摘要、未闭合伏笔与事实、逐章事实证据、角色成长、容器值、最近三章已发生事实和检索记忆编译为一个 `story_state.v2` 状态块。编译结果使用固定分区顺序和总字符预算；大型项目中，最近章节后果、最新的完整证据记录和相关记忆也不会被前面的长摘要挤掉。相同输入会得到字节稳定的输出，有利于 DeepSeek / OpenAI 等支持前缀缓存的服务复用提示词。

逐章事实证据账本只接受能够在对应章节正文中逐字核验的原文片段，并记录来源章节、正文版本和事实状态。`chapter_facts.v2` 还签名章节标题、正文哈希与角色身份列表；其中任一提取输入变化后，旧批次立即退出后续生成的可见范围。重新提取时按章节切片原子替换，重复运行不会累加同一事实。删除章节或主动遗忘时会同时移除对应切片，再按剩余章节的实时顺序重建角色和剧情实体的聚合状态；逐章遗忘 epoch 会阻止更早发出的在途 API 响应把事实重新写回来。设置页可以查看证据覆盖率，并按章节重建旧项目的事实账本；该操作会调用当前文本模型，界面会明确提示可能产生的 API 费用。

状态编译器不建立第二套数据库：原有摘要、实体、角色成长、容器和章节正文仍是唯一数据源。生成开始前会捕获同一份不可变来源快照，创建生成任务与采用候选稿时都会在仓储锁内重新核对；如果写作过程中设定或正文已经变化，旧任务或旧候选不会静默覆盖新状态。

章节有效正文变化时，依赖该章的摘要、聚合摘要、知识库索引和自动提取状态会在正文发布前同步标记过期；仅标题或顺序变化时只失效摘要与索引，带章节 ID 的实体、成长和容器记录继续按实时顺序投影。原记录不会被破坏性删除，手工维护的成长记录与容器值始终保持有效。这样即使应用在写入中途退出，系统最多进入“需要重算”的保守状态，不会继续把旧派生事实注入后续章节。

每个文本请求还会经过 `request_budget.v1` 预算层。模型配置可分别设置上下文窗口和最大输出 Token（默认 64000 / 8000）；完整正文、改写指令等必需输入不会被静默截断，无法装入时会在发起 HTTP 请求前给出配置错误。可裁剪上下文使用固定语义配额，并按照“稳定世界观与时间线 → Story State → 当前章节动态约束”的顺序排列；动态内容变化不会重新瓜分前面稳定区块的份额，从结构上提高 DeepSeek 等前缀缓存的复用机会。连接测试固定使用非推理模式和 256 Token；非推理章节蓝图、事实提取和分段正文也采用更小的阶段上限，避免把全局输出额度带入每一次子调用。DeepSeek 推理模式下推理 Token 与正文共享输出额度，因此 `auto/on` 会保留用户配置的完整输出上限。分步模式会按实际阶段额度为思考输出动态留余量，并在蓝图请求前同时验证最坏分段输入和单次回退分支，避免已经产生一次 API 费用后才发现正文阶段无法继续。内置 DeepSeek 配置使用 `deepseek-v4-flash`，小说写作默认显式关闭 V4 推理模式；设置页仍可选择自动、非推理或推理，并校验温度为有限的 0–2、官方 V4 最大输出不超过 384000 Token。旧版官方内置 `deepseek-chat/reasoner` 配置会在启动及导入旧备份时按原语义安全迁移，自建代理配置不会被改写；配置切换或编辑后，旧的连接测试结果也不会继续显示。

生成内容会先实时流式显示为预览；流结束且完整性、质量检查通过后，系统保存一份待审核候选稿，正式正文仍保持不变。候选审核卡会显示本次调用的模型与提示契约、请求次数、首字耗时（TTFT）、总耗时、Token 字段覆盖率，以及可计算时的前缀缓存命中率。服务商没有返回 usage 时会明确标记为不可观测。文本模型契约测试只连接进程内的回环服务器，不需要真实 API Key，也不会产生供应商费用；真实模型质量仍需由用户使用自己的配置进行验收。

只有点击**采用候选稿**才会把候选内容写入正文；点击拒绝、生成失败、用户停止或被新任务替代都不会覆盖现有正文。

#### 7.2 AI 润色 / 改写选段

### 13. 智能体（Agent）

**智能体**是 NovelSeek Ultra 的旗舰功能——一个能像人一样操作全软件的自主 AI 助手。

点击底部导航栏**正中央**的 🤖 大按钮进入。

#### 13.1 一句话完成整本小说

在输入框输入你的需求，例如：

> "帮我写一部三卷十五章的东方玄幻小说，主角是剑修，带点悲剧色彩。"

智能体将自动执行：
建项目 → 设定境界体系 → 生成世界观 → 生成大纲 → 批量导入角色并生成立绘 → 生成封面 → 规划副本与弧线 → 逐章生成正文

整个过程在**执行流**中实时可见，每一步都有说明。

![智能体执行中](docs/screenshots/13_agent_running.png)

#### 13.2 双智能体与推理级别

在**设置 → 智能体引擎**中可保留经典单智能体，或选择“规划者 + 执行者”的双智能体结构。双智能体提供低、中、高三档推理级别：低档偏向快速直接，中档平衡成本与验证，高档会保留更多执行证据并深入核对依赖、风险与完成标准。设置页决定新建或空白会话的默认级别；已有双智能体会话可在页面底部发送按钮左侧单独调整，调整会同时作用于规划者和执行者，但不会改变文本模型 Profile 自身的 Thinking 开关。任务正在运行、等待用户/确认或等待候选稿审阅时，档位控件会锁定，避免同一段执行混用两个级别。实际保留的执行记录会根据当前模型的上下文窗口、输出额度和固定提示内容动态缩减，避免复杂长任务在发出 API 请求前超出预算。

双智能体生成计划后，页面底部会显示可折叠的规划清单。折叠时保留当前步骤与总进度；展开后可查看每一步的状态、目标、完成标准和建议工具，长清单在独立区域内滚动，不会挤占主要对话记录。输入区还会显示当前会话规划/执行推理请求的缓存命中率与命中 token；服务商未返回缓存用量时会明确显示“暂无供应商数据”，不会把未知值伪装成 0%。

输入区旁的上下文圆环用不同弧段显示固定提示、原始会话历史、输出预留和可用余量，中心百分比表示输入预算占用率。点击圆环可查看 Token 明细并手动压缩。达到 82% 阈值时，系统会在下一次模型请求前自动尝试一次本地确定性压缩；压缩不调用 API、不修改小说项目数据，并保留完整原始执行审计记录。较早内容的摘要带来源指纹，旧摘要与原始历史不一致时不会继续采用；即使摘要很长，也会为最新原始对话尾部保留预算。

#### 13.3 控制执行

- **停止**：随时中断当前任务
- **继续**：中断后可恢复执行
- **插话**：运行中可发送新消息调整方向
- **反问**：智能体需要你决策时会暂停并提问

#### 13.4 半自主模式

敏感操作（如删除章节、回退版本）默认需要逐步确认。可在对话中说 **「始终允许」** 或锁定项目后开启**自动继续**，让智能体全程自主执行。

#### 13.5 后台运行

切到后台或息屏后，智能体通过前台服务继续运行。运行期使用有时限、会续期的 CPU/Wi-Fi 锁与真实进度心跳；等待用户回答、确认或候选稿审核时会释放运行锁，只保留普通通知。

每次规划、模型请求、流式输出和工具边界都会写入可恢复检查点。回到应用或后台心跳触发时，系统会同时检查“运行状态、实际协程、阶段进度时间”，不会只相信界面上的“正在运行”。若确认执行已失活，会保存诊断原因并最多自动恢复 2 次；达到上限后明确暂停并提示检查网络或模型配置，避免无限重试和用户空等。越过写入边界但结果未知的动作会进入“中断待核对”，后续写操作必须由用户确认后才会解除隔离，不会静默重复修改项目。

Android 或厂商省电策略仍可能结束整个应用进程。此时服务会停止伪装运行并留下可点击的恢复通知；重新打开应用后会读取持久化检查点，先诊断再决定是否重试。

#### 13.6 多会话管理

点击顶部会话名称，可新建、重命名、切换或删除会话，各会话独立保存历史。

> ⚠️ 默认备份不包含 API 密钥。设置页可主动勾选“包含 API 密钥”，经二次确认后密钥会以明文写入手动备份文件；此类文件应视同密码妥善保管。未勾选时，新设备需要手动重新配置密钥。

#### 16.2 导入备份（换机恢复）

点击 **「导入备份」** → 选择备份 JSON 文件 → 确认导入，所有项目和内容恢复到新设备。
